Ultra Tools Prompt Composer 사용자 메뉴얼
====================================================

이 문서는 ComfyUI 커스텀 노드 `Ultra Tools Prompt Composer`의 배포본 사용자 메뉴얼입니다.
이 노드는 이미지를 직접 처리하거나 생성하지 않습니다. Positive / Negative 프롬프트 문자열을 만들고, 정리하고, 모델 형식에 맞게 구성하는 프롬프트 문구 노드입니다.

이 메뉴얼은 설치, 연결, 옵션 의미, 실제 사용 흐름, 모델별 권장 사용법, 단독 장면 생성, 외부 프롬프트 구성, 성인 옵션, 문제 해결을 중심으로 설명합니다.

1. 노드 개요
-------------
`Ultra Tools Prompt Composer`는 ComfyUI에서 이미지 생성용 프롬프트를 구성하기 위한 커스텀 노드입니다.
기존 프롬프트를 그대로 보존하면서 스타일 문구를 붙일 수도 있고, 외부 입력 없이 노드 내부 메뉴만으로 새 장면 프롬프트를 만들 수도 있습니다.

노드가 하는 일은 다음과 같습니다.

- 모델 형식에 맞게 positive 프롬프트 구성
- 모델 형식에 맞게 negative 프롬프트 구성
- 자연어형 모델과 태그형 모델의 프롬프트 차이 보정
- 기존 positive 프롬프트에 스타일, 분위기, 구도, 렌즈 느낌 추가
- 외부 입력 없이 단독 장면 프롬프트 생성
- 인물, 장소, 시간, 소품, 조명, 구도, 렌즈 옵션 조합
- 성인 장면용 의상, 분위기, 장소, 포즈, 조명, 구도 문구 구성
- 흑백/수채화/필름/픽셀/유화/애니풍 등 스타일 방향 부여
- 충돌하거나 반복되는 일부 자동 생성 문구를 정리
- 사용자가 직접 입력한 custom_text는 의미 치환 대상으로 삼지 않고, 원문 의도를 보존함

노드가 하지 않는 일은 다음과 같습니다.

- 이미지를 직접 생성하지 않습니다.
- 이미지를 분석하지 않습니다.
- latent, mask, image, video 데이터를 처리하지 않습니다.
- sampler, scheduler, denoise, upscaler 설정을 바꾸지 않습니다.
- 최종 이미지 결과를 보장하지 않습니다.

즉 이 노드는 이미지 생성 파이프라인의 앞쪽에서 프롬프트 문구를 정리해 주는 도구입니다.


2. 설치 방법
------------
1) ZIP 파일의 압축을 풉니다.
2) 압축을 푼 폴더 이름을 아래처럼 둡니다.

```text
comfyui-Ultra-Tools
```

3) 해당 폴더를 ComfyUI의 `custom_nodes` 폴더 안에 넣습니다.

```text
ComfyUI/custom_nodes/comfyui-Ultra-Tools/
```

4) ComfyUI를 완전히 종료한 뒤 다시 실행합니다.
5) 노드 검색창에서 `Ultra Prompt Composer`를 검색합니다.
6) 노드는 보통 `Ultra Tools` 카테고리 아래에 표시됩니다.

설치 확인:

- 폴더 바로 아래에 `__init__.py`가 있어야 합니다.
- 폴더 바로 아래에 `Ultra-Prompt_Composer.py`가 있어야 합니다.
- `web/prompt_composer_locale.js`가 있어야 한국어 UI 라벨이 적용됩니다.
- `data` 폴더가 있어야 스타일/모델/렌즈/구도 데이터가 정상 로드됩니다.

노드가 안 보이면 ComfyUI 콘솔 로그에서 Python import 오류를 먼저 확인하세요.


3. 포함 파일 구성
----------------
배포본의 기본 구성은 다음과 같습니다.

```text
comfyui-Ultra-Tools/
├─ __init__.py
├─ Ultra-Prompt_Composer.py
├─ README.md
├─ 메뉴얼.txt
├─ prompt_composer_data/
│  ├─ README_ko.md
│  ├─ adult_wardrobe.json
│  ├─ auto_style_by_mood.json
│  ├─ explicitness.json
│  ├─ lens_presets.json
│  ├─ model_profiles.json
│  ├─ mood_families.json
│  ├─ scene_framing.json
│  └─ style_dna.json
└─ web/
   └─ prompt_composer_locale.js
```

각 파일의 역할:

- `__init__.py`
  - ComfyUI가 노드를 불러오기 위한 진입 파일입니다.

- `Ultra-Prompt_Composer.py`
  - 노드의 핵심 Python 코드입니다.
  - 프롬프트 생성, 스타일 구성, 모델 형식 변환, 후처리를 담당합니다.

- `web/prompt_composer_locale.js`
  - ComfyUI 화면에서 옵션 이름과 값을 한국어로 보기 좋게 표시합니다.
  - 위젯 표시/숨김과 구버전 워크플로우 값 마이그레이션 보조도 담당합니다.

- `prompt_composer_data/*.json`
  - 모델 프로필, 스타일 DNA, 렌즈, 구도, 분위기, 성인 의상 등의 데이터입니다.

- `메뉴얼/Ultra Tools Prompt Composer 메뉴얼.txt`
  - 이 사용자 메뉴얼입니다.


4. 입출력 구조
--------------
노드 출력은 두 개입니다.

### positive_prompt
이미지 생성에 사용할 최종 positive 프롬프트입니다.

외부 positive 입력이 있으면 기존 프롬프트를 기반으로 스타일과 모델 형식 문구를 결합합니다.
외부 positive 입력이 없으면 노드 내부 옵션으로 단독 장면 프롬프트를 만듭니다.

### negative_prompt
이미지 생성에 사용할 negative 프롬프트입니다.

외부 negative 입력이 있으면 그것을 보존하면서 필요한 기본 negative를 더할 수 있습니다.
외부 negative 입력이 없어도 모델 프로필과 선택 옵션에 맞는 최소 negative가 생성될 수 있습니다.

입력은 다음 두 가지가 핵심입니다.

### external_positive_in
기존 positive 프롬프트를 연결하는 입력입니다.
연결하면 외부 프롬프트 구성 모드로 사용하는 것이 일반적입니다.

```text
텍스트 노드 또는 기존 positive prompt
        ↓
external_positive_in
Ultra Tools Prompt Composer
        ↓ positive_prompt
CLIP Text Encode 또는 모델용 positive 입력
```

### external_negative_in
기존 negative 프롬프트를 연결하는 입력입니다.
연결하지 않아도 노드는 자체 negative를 구성할 수 있습니다.

```text
기존 negative prompt
        ↓
external_negative_in
Ultra Tools Prompt Composer
        ↓ negative_prompt
Negative CLIP Text Encode 또는 모델용 negative 입력
```


5. 가장 빠른 사용법
-------------------
### 기존 프롬프트에 스타일만 붙이고 싶을 때
1. 기존 positive 프롬프트를 `external_positive_in`에 연결합니다.
2. `모델 형식`을 사용 모델에 맞춥니다.
3. `스타일 방향`을 선택합니다.
4. `스타일 반영 방식`을 `균형 적용`으로 시작합니다.
5. 결과가 약하면 `스타일 우선`으로 올립니다.

### 외부 입력 없이 프롬프트를 만들고 싶을 때
1. `external_positive_in`을 연결하지 않습니다.
2. `프롬프트 연결`을 `단독으로 만들기`로 둡니다. 자동 전환을 사용해도 됩니다.
3. `주요 대상`, `장소`, `구도`, `스타일 방향`을 고릅니다.
4. 필요한 경우 `단독 메뉴 표시 범위`를 `상세 메뉴`로 올립니다.
5. 더 풍부한 장면이 필요하면 `장면 디테일 보강`을 사용합니다.

### 태그형 모델에 맞추고 싶을 때
1. `모델 형식`을 SDXL Tag, ILXL / Illustrious Tag, Pony Tag, SD 1.5 Tag 중 맞는 것으로 고릅니다.
2. 스타일, 구도, 렌즈를 선택합니다.
3. 결과 positive는 쉼표 구분 태그 중심으로 나옵니다.
4. 외부 프롬프트가 문장형이면 태그형 모델에서 과하게 길어질 수 있으니 필요한 경우 정리해서 넣으세요.


6. 프롬프트 구성 모드
--------------------
이 노드는 `프롬프트 연결(prompt_source_mode)`과 실제 입력 연결 상태에 따라 동작합니다.

### 자동 전환
외부 positive가 연결되어 있으면 외부 프롬프트를 기반으로 구성합니다.
외부 positive가 없으면 단독 장면 프롬프트를 만듭니다.
대부분의 사용자는 자동 전환을 그대로 사용해도 됩니다.

### 연결 후 스타일 적용
외부 positive를 중심으로 스타일, 분위기, 구도, 모델 형식을 결합합니다.
이미 잘 만든 프롬프트가 있을 때 적합합니다.

### 단독으로 만들기
노드 내부의 subject/location/style 옵션만으로 새 프롬프트를 만듭니다.
외부 positive 입력이 없어야 가장 명확하게 사용할 수 있습니다.

### 스타일만 출력
원본 장면 없이 스타일 문구만 출력합니다.
스타일 프리셋 문구를 다른 노드나 다른 프롬프트에 직접 붙이고 싶을 때 사용합니다.


7. 모델 형식 선택
-----------------
`모델 형식(model_profile)`은 가장 중요한 옵션입니다.
같은 장면이라도 모델마다 잘 먹히는 프롬프트 형식이 다르기 때문입니다.

### Z-Image Natural
문장형 자연어 프롬프트에 적합합니다.
장면 설명, 스타일, 구도, 조명 지시가 자연스러운 문장으로 구성됩니다.

### Qwen Natural
자연어 지시문형 구성에 적합합니다.
이미지 편집형 워크플로우나 지시문형 모델에서 원본 보존/변경 방향을 명확히 적고 싶을 때 좋습니다.

### Flux Natural
자연어 장면 설명에 적합합니다.
너무 많은 짧은 태그보다 문장으로 장면과 스타일을 설명하는 방식이 잘 맞습니다.

### Krea2 Natural
Krea2 계열 자연어 모델용입니다. 범용 대체 프로필이 아니라 Krea2 계열 모델을 사용할 때 선택하는 전용 자연어 프로필입니다.
단순히 문장을 길게 만드는 방식이 아니라, Krea2가 잘 따르는 구체 지시가 되도록 장면을 자연어로 더 명확히 풀어씁니다.

인물 장면에서는 포즈, 몸 방향, 손 위치, 시선, 인물과 배경의 공간 관계처럼 실제 이미지에서 확인할 수 있는 정보를 중심으로 설명합니다.
배경 전용 장면에서는 인물 기준 표현을 억지로 쓰지 않고, 공간 배치, 환경의 방향성, 분위기, 조명, 주요 배경 디테일을 중심으로 설명합니다.
제품/사물 장면에서는 사람의 자세나 의상 같은 표현을 사용하지 않고, 제품 정체성, 재질, 배열, 배치, 조명 방향, 촬영 환경을 중심으로 설명합니다.

Krea2 Natural은 비교적 자세한 자연어 프롬프트에 맞춘 프로필이지만, 사용자가 직접 입력한 custom_text를 다른 의미로 바꾸는 프로필은 아닙니다. custom_text는 사용자의 추가 의도로 보고 원문 의미를 보존합니다.

### Anima Mixed
태그와 짧은 문장 보조를 함께 사용하는 혼합형입니다.
애니/일러스트 계열 모델에서 스타일 태그와 짧은 설명을 같이 주고 싶을 때 사용합니다.
단독 장면에서는 태그 절과 자연어 절이 함께 나오므로 일부 핵심 정보가 두 번 보일 수 있습니다. 다만 나이 보조 태그나 이미 원문에 들어간 의상처럼 과도하게 반복되기 쉬운 항목은 반영력을 해치지 않는 선에서 정리됩니다.

### SDXL Tag
SDXL 계열 태그형 프롬프트에 맞춥니다.
쉼표로 구분된 키워드가 중심입니다.

### ILXL / Illustrious Tag
ILXL, Illustrious 계열 태그형 모델에 맞춥니다.
모델별 rating/source 태그 충돌을 줄이는 방향으로 구성됩니다.

### Pony Tag
Pony 계열 태그형 모델에 맞춥니다.
Pony 계열에서 자주 쓰는 품질/소스/세이프티 태그 흐름에 맞게 구성됩니다.

### SD 1.5 Tag
전통적인 SD 1.5 태그형 프롬프트에 맞춥니다.

모델 형식이 맞지 않으면 스타일이 약하거나, 문장이 너무 길거나, 태그가 부자연스럽게 느껴질 수 있습니다.


8. 분위기와 스타일
------------------
스타일 관련 옵션은 장면의 시각적 방향을 정합니다.

### 분위기(mood_family)
큰 감정/장면 톤을 정합니다.
예를 들어 다음과 같은 방향이 있습니다.

- 기본
- 관능적인 분위기
- 서정적인 분위기
- 클래식 영화 분위기
- 누아르 / 네오누아르
- 몽환적 / 초현실적
- 고딕 로맨스
- 패션 화보
- 팝 네온
- 흑백 영화 분위기
- 따뜻한 노을빛
- 빈티지 감성
- 사이버펑크 / SF
- 수채화 / 회화풍
- 밝고 깨끗한 분위기
- 공포 / 불안한 분위기

`🎲 랜덤 전체`, `🎲 랜덤 변환 스타일`, `🎲 랜덤 전통 매체 화풍` 같은 랜덤 계열도 있습니다.
랜덤은 빠르게 스타일 후보를 테스트할 때 유용합니다.

### 스타일 방향(style_dna)
구체적인 시각 스타일을 정합니다.
예를 들어 다음과 같은 스타일이 있습니다.

- Neutral / Minimal Carryover
- Neon Melancholy / Rain Glass
- Classical Studio Glamour
- Baroque Operatic Atmosphere
- Noir Chiaroscuro
- Symmetric Psychological Coldness
- Mediterranean Sunlight
- Gothic Candle Velvet

9. 스타일 반영 방식과 충돌 정리
-------------------------------
### 스타일 반영 방식(style_strength)
스타일이 원본 프롬프트에 얼마나 강하게 개입할지 정합니다.

- 원본 보존
  - 원본 주체, 의상, 배경을 최대한 유지합니다.
  - 스타일은 가볍게 얹는 느낌입니다.

- 균형 적용
  - 기본 추천값입니다.
  - 원본도 유지하고 스타일도 어느 정도 보이게 합니다.

- 스타일 우선
  - 스타일을 더 강하게 반영합니다.
  - 스타일 테스트나 뚜렷한 변환이 필요할 때 좋습니다.
  - 원본의 의상/배경/조명 일부가 더 크게 바뀔 수 있습니다.

### 충돌 정리(style_conflict_cleanup)
선택한 스타일과 외부 positive 프롬프트가 서로 강하게 충돌할 때 일부 문구를 완화합니다.
이 옵션은 사용자가 켰을 때만 의미가 있으며, 주로 자연어 계열 모델에서 효과가 있습니다.
Z-Image Natural, Qwen Natural, Flux Natural, Krea2 Natural 같은 모델에서 특히 의미가 있습니다.

예를 들어 수채화, 목탄, 연필, 유화 같은 비사진 스타일을 선택했는데 외부 프롬프트에 다음과 같은 사진/카메라/디지털 질감 문구가 강하게 들어 있으면, 선택한 스타일이 약해질 수 있습니다.

```text
photorealistic, camera lens, ultra sharp digital photo, DSLR photo quality, hard photographic sharpness
```

이럴 때 자연어 계열 모델에서는 cleanup이 이런 충돌 문구를 줄이거나, 선택한 스타일과 덜 충돌하는 표현으로 완화할 수 있습니다.
예를 들어 사용자가 외부 positive 프롬프트에 사진적 표현을 넣어 둔 상태에서 수채화나 손그림 계열 스타일을 선택하면, 사진성 문구가 일부 완화되어 스타일 지시가 더 잘 보이도록 정리됩니다.

중요한 차이가 있습니다.
`external_positive_in`은 기존 positive 프롬프트 자체이므로, 사용자가 `style_conflict_cleanup`을 켜면 선택한 스타일에 맞게 일부 사진/카메라 충돌 문구가 완화될 수 있습니다.
반면 `custom_text`는 사용자가 직접 추가한 커스텀 지시어로 취급되며, 스타일/모델 후처리가 그 문장의 의미를 다른 표현으로 바꾸는 대상이 아닙니다.
custom_text 안에 특정 스타일 단어, 조명 단어, 자세 단어가 있더라도 노드는 그 문장을 임의로 다른 의미로 치환하지 않는 방향을 우선합니다.

태그형/혼합형 모델에서는 이 일반 완화가 대부분 적용되지 않습니다.
SDXL Tag, ILXL / Illustrious Tag, Pony Tag, SD 1.5 Tag, Anima Mixed에서는 모델별 태그 구조를 보존하는 쪽이 우선입니다.

단, 흑백 컨텍스트에는 별도 보호 로직이 있습니다.
흑백 무드/스타일을 사용할 때 `neon lights`, `glowing signs`, `cyan/magenta colors` 같은 강한 색상 태그는 태그형/혼합형에서도 흑백 표현에 맞게 정리될 수 있습니다.
이 흑백 정리는 자동 생성 문구와 선택 옵션의 색상 충돌을 줄이기 위한 것이며, 사용자가 custom_text에 직접 쓴 문장을 임의로 다시 쓰는 기능으로 보는 것은 좋지 않습니다.

### 선택 기준
- 스타일이 약하면: `균형 적용` → `스타일 우선`
- 원본이 너무 바뀌면: `스타일 우선` → `균형 적용` 또는 `원본 보존`
- 자연어 모델에서 스타일 충돌이 보이면: `충돌 정리`를 `부드럽게 완화` 또는 `강하게 완화`
- 태그형 모델에서 충돌 태그가 있으면: 외부 태그를 직접 정리하는 것이 가장 확실합니다.


10. 구도, 렌즈, 화면 범위
------------------------
### 구도 / 화면 범위(scene_framing)
이미지에서 주체가 얼마나 크게 보일지, 배경이 얼마나 들어갈지를 정합니다.

대표 예:

- 얼굴 중심
- 가까운 인물
- 상반신
- 허리 위
- 무릎 위 정도
- 전신
- 전신 + 주변 여백
- 넓은 배경 포함
- 위쪽 시점 인물
- 어깨 너머 시점
- 옆모습
- 뒷모습
- 배경이 보이는 인물

구도 옵션은 모델이 정확히 사진 촬영 규칙처럼 따르는 값은 아닙니다.
프롬프트 안에서 화면 범위를 알려주는 힌트라고 이해하면 좋습니다.

### 카메라 / 렌즈 느낌(lens_preset)
렌즈와 시점의 분위기를 정합니다.

대표 예:

- 18mm 초광각 / 공간 강조
- 24mm 넓은 영화 화면
- 35mm 배경이 보이는 인물
- 50mm 자연스러운 인물
- 58mm 빈티지 인물
- 85mm 인물 / 배경 흐림
- 100mm 가까운 디테일
- 135mm 망원 인물
- 아나모픽 와이드 화면
- 위에서 내려다봄
- 아래에서 올려다봄
- 핸드헬드 현장감

렌즈 옵션은 실제 카메라 시뮬레이션이 아니라, 구도와 분위기를 유도하는 문구입니다.


11. 단독 장면 프롬프트 만들기
-----------------------------
단독 장면 프롬프트는 외부 positive 입력 없이 노드 내부 옵션으로 새 prompt를 만드는 기능입니다.

대표 흐름:

1. `프롬프트 연결`을 `단독으로 만들기`로 둡니다.
2. `주요 대상`을 선택합니다.
3. `장소`를 선택합니다.
4. 필요하면 `구도 / 화면 범위`와 `렌즈 느낌`을 선택합니다.
5. `스타일 방향`을 선택합니다.
6. 결과 positive를 CLIP Text Encode로 연결합니다.

기본값만으로도 성인 한국 여성, 긴 어두운 머리, 아늑한 거실, 자연스러운 자세 중심의 기본 프롬프트가 만들어질 수 있습니다.
기본 출력은 모델 형식에 따라 문장형 또는 태그형으로 달라집니다.

단독 구성은 다음 상황에 좋습니다.

- 프롬프트 초안을 빠르게 만들고 싶을 때
- 인물/장소/스타일을 메뉴로 조합하고 싶을 때
- 같은 장면을 여러 모델 형식으로 비교하고 싶을 때
- 기존 프롬프트 없이 테스트 이미지를 만들고 싶을 때


12. 단독 메뉴 표시 범위
----------------------
`단독 메뉴 표시 범위(builder_detail_mode)`는 단독 장면 구성에서 화면에 보이는 메뉴의 범위를 정합니다.
출력 상세도를 직접 높이는 옵션이 아니라, 어떤 단독 옵션을 화면에 보여줄지 정하는 옵션입니다.

### 기본 메뉴
빠르게 사용할 수 있는 핵심 메뉴만 표시합니다.

표시 중심:

- 주요 대상
- 기본 자세
- 행동 / 상황
- 장소
- 장면 디테일 보강

기본 메뉴로 낮추면 화면에서 숨겨지는 상세 인물/장면 값은 서버에서도 자동값으로 무력화됩니다.
따라서 이전에 상세 메뉴에서 골랐던 나이대, 외모 인상, 헤어, 의상, 시간대, 날씨, 소품 등이 화면 뒤에서 몰래 남아 출력에 영향을 주지 않습니다.

### 상세 메뉴
인물과 장면을 더 구체적으로 조절합니다.

추가로 다룰 수 있는 항목:

- 나이대
- 외모 인상
- 외형 / 지역 느낌
- 헤어 스타일
- 의상
- 표정 / 분위기
- 장소 분위기
- 시간대
- 날씨 / 조명
- 장면 소품

### 전체 메뉴
상세 메뉴에 더해 성인 professional 세부 메뉴까지 넓게 표시합니다.
성인 포즈, 성인 조명, 성인 소품, 바디 포커스, 성인 구도 보정 등을 세부적으로 다룰 수 있습니다.

중요:
장면의 풍부함은 `단독 메뉴 표시 범위` 자체가 아니라, 실제로 선택한 세부 옵션과 `장면 디테일 보강`에 의해 달라집니다.


13. 인물/배경/제품 옵션
-----------------------
### 주요 대상(subject_profile)
장면의 중심 대상을 정합니다.

대표 선택지:

- 선택 안함
- 성인 여성 1명
- 성인 남성 1명
- 성인 커플 2명
- 성인 여성 2명
- 성인 남성 2명
- 소규모 성인 그룹
- 배경만 만들기
- 제품 / 사물

### 배경만 만들기
인물 없이 공간/환경 중심 프롬프트를 만들 때 사용합니다.
인물 의상, 표정, 포즈 같은 옵션은 결과에서 빠지는 방향으로 처리됩니다.
구도/렌즈 옵션에 인물 기준 표현이 섞여 있어도 결과에서는 환경 기준 표현으로 정리됩니다. 예를 들어 `full body`, `subject smaller`, `medium shot` 같은 표현은 배경 전용 출력에서 공간/환경 구도 문구로 바뀔 수 있습니다.

예:

```text
empty cozy living room, soft indoor lighting, plants, warm atmosphere
```

### 제품 / 사물
제품 사진, 정물, 오브젝트 중심 프롬프트를 만들 때 사용합니다.
인물 관련 문구보다 제품, 재질, 배치, 조명, 배경을 강조합니다.

예:

```text
cosmetic product on a clean tabletop, controlled indoor setting, soft studio light
```

### 나이대(subject_age)
성인 인물의 나이대 방향을 정합니다.

- 선택 안함
- 20대
- 30대
- 40대
- 50대
- 60대 이상

최종 출력에서는 `20s` 같은 짧은 값만 넣는 것이 아니라, 자연어형에서는 `young adult ... in her early twenties`처럼 모델이 이해하기 쉬운 문장으로 바뀔 수 있습니다.
태그형에서는 `young adult`, `early 20s` 같은 태그 신호로 들어갈 수 있습니다.

### 외모 인상(subject_appearance)
인물의 인상 형용사를 정합니다.
기본값에서는 `beautiful` 같은 평가형 표현을 강제로 넣지 않습니다.

선택 예:

- 자연스러운
- 귀여운
- 아름다운
- 우아한
- 화려한
- 평범한
- 수수한
- 덜 예쁜
- 개성적인

### 외형 / 지역 느낌(subject_ethnicity)
인물의 지역적/외형적 방향을 정합니다.

예:

- Korean
- East Asian
- Southeast Asian
- South Asian
- Western
- Black
- Latino
- Middle Eastern
- mixed-heritage

### 헤어, 의상, 표정, 자세, 행동
상세 메뉴에서는 다음 항목도 조절할 수 있습니다.

- 헤어 스타일
- 일반 의상
- 표정 / 분위기
- 기본 자세
- 행동 / 상황

일반 의상과 성인 의상을 동시에 강하게 지정하면 문구가 길어지거나 충돌할 수 있습니다.
성인 장면을 구성할 때는 성인 의상 쪽을 우선 사용하는 편이 더 명확합니다.

장소에 따라 창문빛, 확산광, 실내 조명 표현으로 자연스럽게 조정될 수 있습니다.

15. 장면 디테일 보강
--------------------
`장면 디테일 보강(auto_extra_detail)`은 단독 장면에서 배경이나 장면 요소를 얼마나 자동으로 보강할지 정합니다.

### 보강 안함
사용자가 직접 고른 값 중심으로 간단하게 구성합니다.

### 안전 보강
장면이 너무 비어 보이지 않도록 약간의 안전한 배경/소품/조명 문구를 더합니다.

### 균형 보강
실내라면 가구, 조명, 커튼, 식물, 책상 같은 주변 요소가 적절히 들어갈 수 있습니다.
외부 장소라면 주변 환경이나 거리/자연 요소가 보강될 수 있습니다.

### 풍부한 배경 보강
장면 묘사를 더 풍부하게 만듭니다.
다만 프롬프트가 길어질 수 있으므로, 모델이 복잡한 장면을 잘 못 따라간다면 균형 보강이 더 안정적일 수 있습니다.

이 옵션은 `단독 메뉴 표시 범위`와 다릅니다.
메뉴 표시 범위는 화면에 보이는 옵션 수를 바꾸고, 장면 디테일 보강은 실제 출력 문구의 풍부함에 영향을 줍니다.


16. 성인 메뉴
-------------
성인 메뉴는 성인 인물, 성인 의상, 성인 분위기, 장소, 조명, 구도 문구를 구성하기 위한 옵션입니다.
이 노드는 이미지 생성 정책을 대신하는 필터가 아니라, 사용자가 선택한 프롬프트 문구를 모델이 읽기 쉬운 형태로 정리하는 노드입니다.

단, 성인 표현과 미성년으로 읽힐 수 있는 표현이 직접 충돌하는 경우에는 의미 충돌을 줄이기 위해 성인 주체 기준으로 정리될 수 있습니다.
예를 들어 성인 톤에서 `teen`, `17-year-old` 같은 표현이 섞이면 최종 프롬프트에서는 성인 주체 표현으로 하모나이즈될 수 있습니다.

### 성인 표현 톤(adult_tone)
성인 분위기의 강도를 정합니다.

- 기본
- 안전한 표현
- 살짝 암시적
- 부드러운 관능
- 강한 관능
- 성인 NSFW
- 강한 성인 NSFW
- 노골적이지 않은 로맨스

이 항목은 프롬프트 문구 방향을 정하는 옵션입니다.
최종 이미지 생성 가능 여부는 사용하는 모델, 워크플로우, 서비스 환경에 따라 달라집니다.

### 성인 의상(adult_wardrobe)
성인 의상 방향을 정합니다.

예:

- 란제리
- 비키니
- 원피스 수영복
- 실크 슬립 드레스
- 코르셋
- 바디수트
- 이브닝 드레스
- 로브
- 스타킹
- 오픈 셔츠
- 미니 드레스
- 하이슬릿 드레스
- 백리스 드레스
- 실크 파자마

의상이 노출도가 높을수록 tone과 문맥이 서로 충돌하지 않도록 내부적으로 문구가 조정될 수 있습니다.

### 성인 메뉴 표시(adult_menu_level)
성인 세부 메뉴의 표시 범위를 정합니다.

- 기본 메뉴
  - 핵심 성인 옵션만 표시합니다.

- 모든 단독 메뉴
  - 성인 포즈, 성인 조명, 성인 소품, 강조 포인트, 구도 보정까지 표시합니다.

성인 메뉴를 기본 메뉴로 낮추면 숨겨지는 professional 성인 필드는 서버에서도 자동값으로 무력화됩니다.
따라서 이전에 professional에서 골랐던 성인 포즈나 조명이 화면 뒤에 남아 몰래 반영되지 않습니다.

### 성인 노출 수준(adult_exposure_level)
노출 정도를 정합니다.

예:

- 옷을 입은 관능
- 노출 있는 의상
- 란제리 / 속옷
- 수영복
- 암시적 누드 / 가림
- 시트로 가린 누드
- 누드
- 상의 탈의
- 바디콘 패션

### 성인 장소(adult_scene_privacy)
성인 장면의 장소/프라이버시 방향을 정합니다.
이 항목이 `선택 안함`이 아니면 일반 장소보다 우선될 수 있습니다.

예:

- 사적인 실내
- 침실 / 호텔방
- 부두아르 침실
- 럭셔리 호텔 스위트
- 프라이빗 라운지
- 스튜디오
- 드레싱룸
- 욕실
- 스파 / 목욕
- 수영장 / 해변

일반 장소를 유지하고 싶다면 성인 장소를 `선택 안함`으로 두고 `장소(location_type)`를 사용하세요.

### 성인 분위기(adult_scene_mood)
성인 장면의 감정/연출 톤을 정합니다.

예:

- 소프트 부두아르
- 따뜻한 로맨틱 친밀감
- 패션 화보식 관능
- 럭셔리 호텔의 저녁
- 사적인 거울 장면
- 누아르 친밀감
- 스파처럼 차분한
- 풀사이드 글래머
- 해변 석양 관능
- 스튜디오 글래머
- 부드러운 아침 분위기

### 성인 포즈(adult_pose_style)
professional 메뉴에서 사용할 수 있는 포즈 방향입니다.
다른 성인 필드를 건드리지 않고 포즈만 선택해도 해당 포즈 문구가 단독으로 반영됩니다.

예:

- 편안한 관능 포즈
- 기대어 누운 관능 포즈
- 앉은 관능 포즈
- 당당하게 서 있는 포즈
- 어깨 너머로 돌아봄
- 거울 옆에 서 있음
- 풀사이드에 기대어 쉼
- 뒤돌아선 실루엣

### 성인 조명(adult_lighting)
성인 장면의 조명 연출을 정합니다.

예:

- 따뜻한 침대 조명
- 로우키 그림자
- 부드러운 창가 역광
- 촛불 느낌
- 스튜디오 림라이트
- 네온 라운지 조명
- 김 서린 욕실 조명
- 석양 역광

태그형 모델에서는 자연어형 조명 문구와 태그형 조명 문구가 중복되지 않도록 정리됩니다.

### 성인 소품, 강조 포인트, 구도 보정
professional 메뉴에서는 다음도 조절할 수 있습니다.

- 성인 소품
- 강조 포인트
- 구도 보정

프롬프트가 너무 길어지거나 특정 요소가 과하게 강조되면 professional 옵션을 줄이고 essential 옵션 중심으로 사용하는 것이 좋습니다.


17. Negative 프롬프트
--------------------
`negative_prompt`는 다음을 바탕으로 구성됩니다.

- 외부 negative 입력
- 모델 프로필별 기본 negative
- 미성년/성인 의미 충돌 방지 문구
- 품질 저하 방지용 최소 문구

이 노드는 negative를 과도하게 길게 만들지 않는 방향을 우선합니다.
특히 Turbo, CFG 1, 일부 자연어형 모델에서는 negative가 약하게 작동하거나 거의 작동하지 않을 수 있습니다.
따라서 negative에 모든 문제를 넣기보다 positive를 명확하게 쓰는 것이 더 중요할 수 있습니다.

외부 negative를 연결하면 사용자의 negative를 보존하면서 필요한 기본 negative가 결합됩니다.
외부 negative가 없으면 모델 형식에 따라 최소 negative만 생성될 수 있습니다.


18. 커스텀 문구와 외부 프롬프트
-------------------------------
### external_positive_in
외부 positive 프롬프트는 이미 만들어 둔 기본 positive, 다른 텍스트 노드에서 온 positive, 또는 사용자가 직접 연결한 원본 프롬프트입니다.
노드는 이 입력을 완전히 새로 쓰는 것이 아니라, 선택한 모델 형식, 스타일, 분위기, 구도, 렌즈, 단독 옵션과 결합합니다.

외부 positive는 프롬프트의 본문에 가깝습니다.
따라서 `style_conflict_cleanup`을 켜면, 선택한 스타일과 강하게 충돌하는 사진/카메라/디지털 질감 표현이 일부 완화될 수 있습니다.
예를 들어 수채화 스타일을 선택했는데 외부 positive에 `DSLR photo quality`나 `hard photographic sharpness` 같은 표현이 있으면, 자연어 계열 모델에서는 스타일이 덜 충돌하도록 일부 표현이 조정될 수 있습니다.

이 동작은 사용자가 의도적으로 선택한 충돌 정리 기능입니다.
외부 positive를 절대 한 글자도 바꾸면 안 되는 원문으로 쓰고 싶다면 `style_conflict_cleanup`을 끄는 것이 가장 안전합니다.

### external_prompt_mode
외부 프롬프트와 스타일 문구를 어떤 순서로 합칠지 정합니다.

- 원본 뒤에 추가
  - 기존 프롬프트 뒤쪽에 스타일 문구를 붙입니다.
  - 가장 일반적인 사용법입니다.
  - 원본 장면을 먼저 제시하고, 그 뒤에 스타일/모델 문구를 보강하고 싶을 때 사용합니다.

- 스타일 앞에 배치
  - 스타일 문구를 먼저 놓고 원본을 뒤에 둡니다.
  - 스타일을 모델이 먼저 보게 하고 싶을 때 사용합니다.
  - 스타일 반영이 약하게 느껴질 때 테스트해 볼 수 있습니다.

- 스타일만 출력
  - 원본 프롬프트를 빼고 스타일 문구만 출력합니다.
  - 기존 positive를 사용하지 않고, 선택한 스타일/모델 보조문만 따로 확인하거나 다른 노드와 조합하고 싶을 때 사용합니다.

### 추가 문구(custom_text)
`custom_text`는 사용자가 직접 입력하는 추가 지시어입니다.
외부 positive와 달리, 노드는 custom_text의 의미를 스타일/모델 후처리 대상으로 삼아 다른 표현으로 바꾸지 않는 방향을 우선합니다.
즉 custom_text에 사용자가 직접 쓴 문장은 최종 프롬프트 안에서도 같은 의미로 남아야 합니다.

custom_text는 다음처럼 쓰는 것이 좋습니다.

```text
keep the original pose and background
make the lighting warmer and softer
apply a faded film photo look without changing the subject
keep the city signs natural and incidental
use a cleaner product photography layout
```

이런 문구는 사용자의 추가 의도를 직접 말해 주므로, 모델이 무엇을 유지하고 무엇을 바꿀지 이해하는 데 도움이 됩니다.

피하는 것이 좋은 예:

```text
make it better
add everything
more beautiful and more detailed and more cinematic
change the style but keep everything and change everything
```

이런 문구는 방향이 모호하거나 서로 모순될 수 있습니다. 가능한 한 무엇을 유지할지, 무엇을 바꿀지, 어느 부분을 강조할지 구체적으로 쓰는 것이 좋습니다.

custom_text 보존 원칙:

- custom_text는 사용자가 직접 쓴 추가 지시어로 취급됩니다.
- 노드는 custom_text 안의 단어를 임의로 다른 의미의 단어로 바꾸지 않는 방향을 우선합니다.
- custom_text에 `elegant posture`, `controlled beauty lighting`, `clear hand-rendered subject quality`처럼 내부 자동 생성 문구와 우연히 겹치는 표현이 들어 있어도, 그것이 사용자가 직접 쓴 문장이라면 의미 치환 대상이 아닙니다.
- 프롬프트 문장으로 자연스럽게 이어지도록 앞뒤 구분자, 공백, 마침표 같은 문장 연결이 정리될 수는 있습니다.
- 외부 positive와 custom_text가 완전히 같은 문장을 반복할 때는 중복을 줄이기 위해 한 번만 남을 수 있습니다.

정리하면, external_positive_in은 스타일과 결합되는 원본 positive이고, custom_text는 사용자가 직접 덧붙이는 추가 지시어입니다. 둘 다 사용자의 의도를 담지만, custom_text는 특히 원문 의미 보존을 우선합니다.


19. 자연어형 / 태그형 / 혼합형 차이
----------------------------------
### 자연어형
Z-Image, Qwen, Flux, Krea2 Natural에 적합합니다.
문장형 설명을 중심으로 합니다.

예:

```text
Render the scene as a faded analog film photograph with washed-out colors, visible fine film grain, soft halation, and a nostalgic print finish.
```

장점:

- 장면 설명이 자연스럽습니다.
- 보존 지시와 변경 지시를 명확히 쓰기 좋습니다.
- 스타일 충돌 정리가 비교적 잘 작동합니다.

### 태그형
SDXL, ILXL, Pony, SD 1.5에 적합합니다.
쉼표로 구분된 태그 중심입니다.

예:

```text
analog photo, 35mm film, faded film photo, washed-out colors, film grain, soft halation
```

장점:

- 짧고 강한 키워드 신호를 줄 수 있습니다.
- 모델별 품질/소스 태그와 잘 맞습니다.
- 기존 태그형 워크플로우와 연결하기 쉽습니다.

### 혼합형
Anima Mixed처럼 태그와 짧은 보조문을 함께 씁니다.

예:

```text
masterpiece, best quality, anime style, black and white, classic film. Render with crisp tonal separation and classic monochrome film atmosphere.
```

장점:

- 태그 신호와 설명 문구를 함께 줄 수 있습니다.
- 애니/일러스트 계열 스타일 반영에 유용합니다.


20. 모델별 추천 사용법
---------------------
### Z-Image Natural
- 자연어 문장형으로 사용하세요.
- 외부 프롬프트가 길어도 비교적 자연스럽게 구성됩니다.
- 스타일을 강하게 보고 싶으면 `스타일 우선`을 사용하세요.
- 충돌 정리는 자연어 계열에서 특히 의미가 있습니다.

### Qwen Natural
- 지시문을 분명하게 쓰는 편이 좋습니다.
- `keep`, `preserve`, `replace`, `change` 같은 명확한 동사가 도움이 됩니다.
- 이미지 편집형 워크플로우에서는 원본 보존 문구를 짧고 정확하게 쓰세요.

### Flux Natural
- 너무 많은 태그보다 장면 설명 중심이 좋습니다.
- 스타일 문구는 문장 안에 자연스럽게 들어가는 것이 좋습니다.

### SDXL Tag
- 쉼표 구분 태그 중심으로 사용하세요.
- 외부 프롬프트가 자연어 문장형이면 너무 긴 문장이 태그열에 섞일 수 있습니다.

### ILXL / Illustrious Tag
- 모델별 rating/source 태그 충돌에 주의하세요.
- 이 노드는 불필요하거나 충돌할 수 있는 일부 태그를 정리합니다.

### Pony Tag
- Pony 계열 품질/소스 태그 흐름을 사용합니다.
- 외부 태그와 중복되는 경우 태그가 너무 길어지지 않도록 확인하세요.

### SD 1.5 Tag
- 전통적인 짧은 키워드 중심 구성이 잘 맞습니다.
- 과도한 자연어 문장은 줄이는 것이 좋습니다.

### Anima Mixed
- 태그와 짧은 보조문을 함께 사용합니다.
- custom_text가 스타일 레이어에서 사라지지 않도록 보존됩니다.
- 애니/일러스트 계열 모델에서 스타일 지시를 좀 더 명확히 줄 수 있습니다.


21. 대표 스타일 사용 팁
----------------------
### Black & White Classic
흑백 영화/사진 느낌을 만듭니다.
강한 색상 태그가 들어온 경우 흑백 표현에 맞게 정리될 수 있습니다.

어울리는 장면:

- 누아르 인물
- 클래식 초상
- 강한 명암
- 도시 거리
- 스튜디오 인물

### Vintage Film Look
오래된 필름 사진 느낌입니다.
색이 살짝 빠지고, 필름 그레인과 부드러운 할레이션이 들어갑니다.

어울리는 장면:

- 일상 스냅
- 창가 인물
- 여행 사진
- 오래된 잡지 사진

### Dream Pastel Diffusion
몽환적인 파스텔 색감과 부드러운 확산광 중심입니다.
우주, 별, 요정, 떠다니는 물체를 자동으로 추가하는 스타일은 아닙니다.
그런 장면 요소가 필요하면 custom_text에 직접 적는 것이 좋습니다.

### Watercolor / Painterly
수채화/회화 느낌입니다.
자연어 계열에서 photorealistic, camera lens, ultra sharp digital photo 같은 문구와 충돌할 수 있습니다.
필요하면 충돌 정리를 사용하세요.

### Graphite Pencil Sketch
연필 스케치 느낌입니다.
섬세한 선, 흑연 질감, 종이 질감, 손그림 느낌을 강조합니다.
사진적인 문구와 같이 쓰면 스타일이 약해질 수 있습니다.

### Cyberpunk Neon
네온, 젖은 거리, 반사광, 미래 도시 느낌에 적합합니다.
흑백 무드와 함께 쓸 경우 색상 표현 일부가 흑백 톤에 맞게 정리될 수 있습니다.

### Chibi Style
작고 귀여운 비율과 치비 스타일을 유도합니다.
인물 실사 보존이 중요한 경우 강하게 적용하면 비율이 많이 바뀔 수 있습니다.

### 3D Collectible Figure
피규어, 장난감, 수집품 렌더 느낌에 적합합니다.
제품/사물 프롬프트와도 잘 어울릴 수 있습니다.


22. 예시 워크플로우
------------------
### 예시 1: 기존 인물 프롬프트에 색바랜 필름 느낌 추가
```text
external_positive_in:
a Korean woman standing near a large window in a cozy room, soft natural light

모델 형식:
Z-Image Natural

스타일 방향:
Vintage Film Look

스타일 반영 방식:
균형 적용
```

결과 방향:
원본 인물과 실내 장면은 유지하면서 faded film photo, washed-out colors, film grain, soft halation 계열 표현이 추가됩니다.

### 예시 2: 태그형 모델에서 흑백 클래식 스타일
```text
모델 형식:
SDXL Tag

스타일 방향:
Black & White Classic

구도 / 화면 범위:
상반신

렌즈 느낌:
85mm portrait shallow DOF
```

결과 방향:
black and white, classic film, monochrome tonal contrast, portrait framing 계열 태그가 중심이 됩니다.

### 예시 3: 단독 실내 인물 프롬프트
```text
프롬프트 연결:
단독으로 만들기

주요 대상:
성인 여성 1명

외형 / 지역 느낌:
Korean

장소:
아늑한 거실

구도:
허리 위

스타일 방향:
Soft Romantic Glow
```

결과 방향:
성인 한국 여성, 아늑한 거실, 허리 위 구도, 부드러운 로맨틱 조명 중심의 프롬프트가 구성됩니다.

### 예시 4: 배경만 만들기
```text
주요 대상:
배경만 만들기

장소:
도서관

장소 분위기:
빈티지 클래식

시간대:
저녁

장면 소품:
책 / 잡지
```

결과 방향:
인물 없이 도서관 배경, 오래된 책, 저녁 조명, 클래식한 실내 분위기가 중심이 됩니다.

### 예시 5: 제품 사진 느낌
```text
주요 대상:
제품 / 사물

장소:
스튜디오 배경

장소 분위기:
미니멀 / 모던

장면 소품:
화장품 제품

렌즈 느낌:
100mm macro detail
```

결과 방향:
제품, 재질, 배치, 깔끔한 배경, 매크로 디테일 중심의 프롬프트가 구성됩니다.

### 예시 6: 성인 장면 세부 구성
```text
성인 표현 톤:
부드러운 관능

성인 메뉴 표시:
모든 단독 메뉴

성인 의상:
실크 슬립 드레스

성인 장소:
침실 / 호텔방

성인 포즈:
기대어 누운 관능 포즈

성인 조명:
따뜻한 침대 조명
```

결과 방향:
성인 인물, 실크 의상, 침실/호텔룸, 부드러운 조명과 포즈 중심의 프롬프트가 구성됩니다.


23. 자주 헷갈리는 점
--------------------
### 외부 positive가 연결되면 단독 옵션은 모두 무시되나요?
외부 positive가 중심이 됩니다.
단독 장면 생성용 subject/location 옵션은 외부 프롬프트 구성에서는 제한적으로만 의미가 있거나 보이지 않을 수 있습니다.
단독 장면을 만들고 싶다면 external_positive_in을 연결하지 않는 것이 가장 명확합니다.

### 단독 메뉴 표시 범위가 출력 상세도를 바꾸나요?
직접 바꾸는 옵션은 아닙니다.
화면에 보이는 단독 메뉴의 범위를 바꾸는 옵션입니다.
출력의 풍부함은 `장면 디테일 보강`과 실제 선택한 세부 옵션이 결정합니다.

### 기본 메뉴로 낮추면 예전에 고른 상세값이 남나요?
남아도 서버에서 자동값으로 무력화됩니다.
따라서 화면에 보이지 않는 상세값이 뒤에서 몰래 출력에 반영되지 않습니다.

### 성인 메뉴도 숨기면 값이 남나요?
성인 professional 메뉴를 숨기면 해당 pro 필드는 서버에서 자동값으로 무력화됩니다.

### adult_pose_style만 골라도 작동하나요?
네. 전체 메뉴에서 성인 포즈만 선택해도 해당 포즈 문구가 반영됩니다.

### 스타일 충돌 정리는 태그형에서도 작동하나요?
일반 사진/카메라/디지털 질감 완화는 주로 자연어 계열에서 작동합니다.
태그형/혼합형에서는 대부분 보존됩니다.
단, 흑백 컨텍스트의 색상 충돌 정리는 별도로 작동할 수 있습니다.

또한 충돌 정리는 custom_text를 억지로 다시 쓰는 기능이 아닙니다.
사용자가 custom_text에 직접 적은 추가 지시어는 원문 의미를 보존하는 쪽이 우선이며, 충돌 정리는 주로 외부 positive와 자동 생성 스타일 문구 사이의 충돌을 줄이기 위한 기능으로 이해하는 것이 좋습니다.

### custom_text가 사라지거나 다른 말로 바뀔 수 있나요?
custom_text는 사용자가 직접 입력한 추가 지시어로 취급되며, 의미를 바꾸는 후처리 대상이 아닙니다.
따라서 사용자가 쓴 문장은 최종 프롬프트에서도 같은 의미로 남아야 합니다.

다만 프롬프트 전체를 자연스럽게 이어 붙이기 위해 공백, 쉼표, 마침표 같은 연결부가 정리될 수 있습니다.
또한 외부 positive와 custom_text가 완전히 같은 문장을 반복하면 중복을 줄이기 위해 한 번만 남을 수 있습니다.

custom_text를 한 글자 단위로 절대 보존해야 하는 원문 보관 용도로 쓰기보다는, 최종 positive에 반드시 포함되었으면 하는 추가 지시어로 사용하는 것이 좋습니다.

### 간판, 메뉴판, 네온 사인을 넣어도 되나요?
네. 이 노드는 도시, 카페, 상점, 역 같은 장소에서 자연스러운 안내판/간판/네온 사인을 무조건 막지 않습니다.
필요하면 외부 프롬프트나 custom_text에 직접 적으세요.

### 흑백 스타일인데 neon이 들어가면 어떻게 되나요?
색상 자체가 중요한 네온 색 표현은 흑백 톤에 맞게 바뀔 수 있습니다.
장면의 네온 간판이나 도시 분위기 자체는 유지하려는 방향입니다.

### 제품/사물 모드에서 인물 문구가 들어가나요?
제품/사물 모드에서는 제품, 재질, 배치, 배경, 구도가 중심이 되도록 후처리됩니다.
인물 보존 문구가 제품 보존 문구로 정리될 수 있습니다.
배경만 만들기에서는 인물 기준 구도 문구가 환경 기준 문구로 바뀔 수 있습니다.


24. 문제 해결
-------------
### 노드가 검색되지 않음
- 폴더 위치를 확인하세요.
- `custom_nodes/comfyui-Ultra-Tools/` 안에 `__init__.py`가 바로 있어야 합니다.
- ComfyUI를 완전히 재시작하세요.
- 콘솔 로그에서 Python import 오류를 확인하세요.

### 한국어 라벨이 안 보임
- `web/prompt_composer_locale.js` 파일이 있는지 확인하세요.
- 브라우저 새로고침을 해보세요.
- ComfyUI 프론트엔드 캐시가 남아 있으면 강력 새로고침 또는 캐시 삭제가 필요할 수 있습니다.

### 프롬프트가 너무 길어짐
- `장면 디테일 보강`을 낮추세요.
- 성인 professional 옵션을 줄이세요.
- 외부 프롬프트의 중복 태그를 줄이세요.
- 스타일을 `원본 보존` 또는 `균형 적용`으로 낮추세요.

### 스타일이 약하게 느껴짐
- `스타일 반영 방식`을 `스타일 우선`으로 올려보세요.
- 자연어 모델에서는 `충돌 정리`를 켜보세요.
- 외부 프롬프트에 photorealistic, clean digital, ultra sharp, HDR 같은 문구가 강하게 들어 있는지 확인하세요.

### 원본이 너무 많이 바뀜
- `스타일 반영 방식`을 낮추세요.
- 구도/렌즈/성인 세부 옵션을 줄이세요.
- custom_text에 `keep the original subject, pose, outfit, and background`처럼 보존 문구를 짧게 넣어보세요.

### 태그형 모델에서 문장처럼 보이는 문구가 많음
- 모델 형식이 맞는지 확인하세요.
- Anima Mixed는 의도적으로 태그와 짧은 문장이 함께 나옵니다.
- 순수 태그형을 원하면 SDXL Tag, ILXL / Illustrious Tag, Pony Tag, SD 1.5 Tag를 사용하세요.
- 태그형 모델에서는 일부 긴 스타일/구도 표현이 더 짧은 태그형 표현으로 정리될 수 있습니다.

### 성인 장소와 일반 장소가 충돌함
- `성인 장소`가 auto가 아니면 성인 장소가 우선될 수 있습니다.
- 일반 장소를 유지하고 싶으면 성인 장소를 `선택 안함`으로 두세요.

### 단독 모드에서 세부값이 예상과 다름
- `단독 메뉴 표시 범위`를 확인하세요.
- 기본 메뉴에서는 숨겨진 상세값이 자동값으로 무력화됩니다.
- 세부 나이/헤어/의상/시간/소품을 쓰고 싶으면 상세 메뉴 이상으로 올리세요.


25. 좋은 프롬프트를 위한 요령
-----------------------------
1) 먼저 사용할 모델 형식을 정확히 고르세요.
2) 외부 프롬프트를 쓸지 단독 장면을 만들지 정하세요.
3) 스타일은 처음에는 `균형 적용`으로 시작하세요.
4) 스타일이 약하면 `스타일 우선`으로 올리세요.
5) 원본 보존이 중요하면 `원본 보존`을 사용하세요.
6) custom_text는 짧고 명확하게 쓰세요.
7) 성인 메뉴는 필요한 항목만 켜세요.
8) 태그형 모델에서는 너무 긴 자연어 문장을 줄이세요.
9) 배경만 만들기와 제품/사물 모드는 인물 옵션과 섞지 않는 것이 좋습니다.
10) 프롬프트가 길어질수록 모델이 일부 지시를 무시할 수 있습니다.

좋은 custom_text 예:

```text
keep the original pose and background
make the lighting warmer and softer
apply a faded film photo look without changing the subject
keep the city signs natural and incidental
use a clean product photography layout
preserve the same outfit and facial identity
```

피하는 것이 좋은 custom_text 예:

```text
make it good
add many things
better quality please
change everything but keep everything
do all styles at once
```

좋은 프롬프트는 길이가 아니라 명확성이 중요합니다.


26. 배포본 사용 시 참고 사항
---------------------------
이 노드는 프롬프트 문구를 구성하는 도구입니다.
최종 이미지는 사용하는 모델, LoRA, sampler, scheduler, seed, CFG, 해상도, ControlNet, 업스케일러, 후처리 노드의 영향을 크게 받습니다.

프롬프트가 정확해도 모델이 모든 지시를 항상 그대로 따르지는 않습니다.
특히 다음 요소는 모델과 워크플로우 영향을 많이 받습니다.

- 인물 동일성
- 얼굴/손 디테일
- 의상 보존
- 복잡한 배경 소품
- 구도와 렌즈 효과
- 성인 표현 강도
- 텍스트/간판 표현
- 스타일 강도

이 노드는 다음 목적에 가장 적합합니다.

- 모델 형식에 맞는 프롬프트 구성
- 자연어/태그/혼합형 모델 간 문구 차이 정리
- 기존 프롬프트에 스타일 방향 결합
- 단독 장면 프롬프트 초안 생성
- 성인 장면용 문구를 체계적으로 구성
- 반복되거나 충돌하는 일부 자동 생성 문구를 정리
- 사용자 입력의 의미를 보존하면서 프롬프트를 더 예측 가능한 구조로 만들기

최종 결과가 마음에 들지 않으면 노드 옵션만 바꾸기보다 모델 설정, LoRA, sampler, 해상도, seed도 함께 조정하는 것이 좋습니다.


끝.


부록. 단독 메뉴 확장 메모
-------------------------

### 표정 / 분위기 확장
