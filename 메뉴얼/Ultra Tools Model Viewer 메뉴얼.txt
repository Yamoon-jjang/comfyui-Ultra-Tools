Ultra Tools Model Viewer 메뉴얼
===============================

1. 노드 소개
------------
Ultra Tools Model Viewer는 현재 ComfyUI 워크플로우에서 참조되는 모델 파일을 찾아 종류별로 정리해 보여주는 정보용 노드입니다.
전체 모델 저장소를 나열하는 것이 아니라, 현재 그래프의 노드 값과 워크플로우 정보를 조사하여 실제로 참조되는 모델 후보를 확인하는 용도입니다.
출력 소켓이 없는 UI/정보용 OUTPUT_NODE이며 모델 자체를 로드하거나 워크플로우 값을 변경하지 않습니다.

2. 노드 찾기
------------
노드 이름: Ultra Tools Model Viewer
카테고리: Ultra Tools

3. 표시 내용
------------
- models: 읽기 전용 결과 영역입니다.
- 현재 워크플로우에서 발견한 모델을 카테고리별로 정리합니다.
- 발견된 모델의 파일명과 실제 파일 크기를 표시합니다.
- 현재 소스는 Checkpoint/UNET/VAE/CLIP/Text Encoder/LoRA/ControlNet/IPAdapter/Upscale/GGUF/Nunchaku 등 다양한 모델 참조 형식을 판별하도록 구성되어 있습니다.

4. 동작 방식
------------
프런트엔드가 현재 워크플로우와 모델 후보 정보를 서버에 전달하면 서버가 ComfyUI의 실제 모델 경로에서 해당 파일을 확인합니다.
노드의 모델 관련 위젯, 속성, 입력 값과 일부 태그형 참조를 분석하며 일반 UI 라벨을 모델명으로 오인하지 않도록 모델 관련 키와 노드 종류를 제한하여 검사합니다.

5. 기본 사용법
--------------
1) 확인할 워크플로우를 엽니다.
2) Ultra Tools Model Viewer를 추가합니다.
3) models 영역에서 현재 워크플로우에서 발견된 모델을 확인합니다.
4) 워크플로우의 모델 선택이나 그래프 상태가 변경되면 노드가 변경 상태를 감지하여 결과를 갱신합니다.

6. 결과가 비어 있을 때
----------------------
`No models in workflow`가 표시되면 현재 워크플로우에서 확인 가능한 모델 참조가 없거나, 해당 모델 파일을 현재 ComfyUI 모델 경로에서 찾지 못했을 수 있습니다.
커스텀 노드가 아주 특수한 자체 형식으로 모델명을 저장하는 경우 자동 판별 범위 밖일 수도 있습니다.

7. Ultra Tools Model Viewer (All)과의 차이
-----------------------------------------
Ultra Tools Model Viewer: 현재 워크플로우에 사용된 모델 중심으로 확인합니다.
Ultra Tools Model Viewer (All): ComfyUI 모델 저장소를 카테고리별로 직접 스캔합니다.

8. 안전성
---------
- 모델 파일을 삭제하거나 이동하지 않습니다.
- 워크플로우의 모델 선택 값을 변경하지 않습니다.
- 현재 모델 참조를 읽고 실제 파일 존재 여부와 크기를 확인하는 정보용 기능입니다.

9. 설치
-------
ComfyUI/custom_nodes/comfyui-Ultra-Tools/ 위치에 통합 패키지를 설치한 뒤 ComfyUI를 완전히 재시작하고 브라우저를 새로고침합니다.
