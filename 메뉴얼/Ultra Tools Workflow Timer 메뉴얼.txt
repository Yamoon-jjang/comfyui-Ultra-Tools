Ultra Tools Workflow Timer 사용 메뉴얼
====================================

1. 노드 소개
------------
Ultra Tools Workflow Timer는 현재 워크플로우의 실행 시간을 실시간으로 표시하고, 완료된 실행 기록과 평균 시간을 같은 노드에서 확인하는 모니터링 노드입니다.

노드 이름: Ultra Tools Workflow Timer
카테고리: Ultra Tools
내부 노드 키: UltraWorkflowTimer

이 노드는 실행 결과를 다른 노드로 전달하는 처리 노드가 아니라 OUTPUT_NODE 형태의 표시/측정 노드입니다.

2. 기본 사용법
-------------
1) Add Node에서 "Ultra Tools Workflow Timer"를 추가합니다.
2) 워크플로우를 Queue/Run 합니다.
3) 실행이 시작되면 Time 영역이 Idle에서 실시간 경과 시간으로 바뀝니다.
4) 실행이 끝나면 History에 최근 실행 시간이 추가됩니다.
5) Stats에는 전체 실행 횟수와 평균 시간이 표시됩니다.

별도의 연결선은 필요하지 않습니다. 같은 루트 워크플로우 안에 노드를 두기만 하면 됩니다.

3. 화면 항목
-----------
Time
- 현재 실행 중이면 경과 시간을 실시간으로 표시합니다.
- 실행 중이 아니면 Idle로 표시됩니다.

Stats
- Total: 누적 실행 횟수
- Avg: 누적 평균 실행 시간
- 런타임 표시용 위젯이며 워크플로우 JSON의 일반 입력값으로 저장하지 않도록 처리되어 있습니다.

History
- 최근 완료된 실행 시간을 위에서부터 표시합니다.
- 최대 100개의 최근 기록을 메모리에 유지합니다.
- 읽기 전용 표시 영역으로 사용합니다.

4. 워크플로우별 기록 분리
------------------------
타이머는 여러 워크플로우 탭이나 서로 다른 루트 워크플로우를 가능한 한 구분해서 각각의 시간 기록을 유지하도록 설계되어 있습니다.
워크플로우 A → B → A처럼 이동했을 때 같은 런타임 워크플로우로 판별되면 A의 기존 기록을 다시 보여줍니다.
복제/드래그 로드처럼 겉보기 내용이 비슷한 워크플로우가 서로 기록을 섞지 않도록 그래프와 노드 객체의 런타임 식별 정보도 함께 사용합니다.

5. 실행 중 표시와 종료 판정
-------------------------
실행 시작 시 실시간 표시가 시작되고, 완료/실행 종료 이벤트를 기준으로 기록을 확정합니다.
비정상적인 이벤트 누락 때문에 계속 실행 중처럼 남는 상황을 줄이기 위한 watchdog 로직도 포함되어 있습니다.

6. 주의사항
-----------
- 이 노드는 GPU 연산 시간을 직접 계측하는 프로파일러가 아닙니다. ComfyUI 워크플로우 실행의 체감 경과 시간을 측정합니다.
- 브라우저를 새로 시작하거나 ComfyUI 프런트엔드 세션이 완전히 초기화되면 메모리의 누적 통계가 초기화될 수 있습니다.
- 여러 타이머 노드를 같은 워크플로우에 넣어도 같은 워크플로우 상태를 표시하도록 동작합니다.
- 타이머를 삭제해도 다른 생성 노드의 실행 결과에는 영향을 주지 않습니다.

7. 추천 용도
-----------
- 모델/샘플러/해상도 변경 전후 생성 시간 비교
- 최적화 노드 적용 전후 체감 성능 비교
- 긴 영상/이미지 워크플로우의 실행 시간 확인
- 반복 생성에서 평균 실행 시간 확인
